# Web Scraping - Coursera Assignment

This project is a solution to the Coursera assignment: **Following Links in HTML Using Python and BeautifulSoup**  
Part of the course: *Using Python to Access Web Data*

---

## 🚀 What this script does

- Takes a URL, count, and position as input.
- Scrapes the given URL and follows links for a number of times.
- Prints out the last name found in the sequence of links.
